# ------------------------------------------------------------
# ¿POR QUE LAS VERSIONES ESTAN FIJAS?
# ------------------------------------------------------------
# El worker consume la cola con BRPOP (comando BLOQUEANTE) sobre
# Redis / Upstash. A partir de redis-py 8.0 cambio el valor por
# defecto de socket_timeout:
#
#     redis/_defaults.py  ->  DEFAULT_SOCKET_TIMEOUT = 5   (5s)
#
# Antes (redis-py 4.x/5.x) ese valor era None = esperar sin limite.
# Con redis 8, un BRPOP con timeout=30 hace que el socket del
# cliente se rinda a los 5s aunque el servidor siga esperando los
# 30s, provocando el error en bucle:
#
#     redis.exceptions.TimeoutError: Timeout reading from socket
#
# El codigo ya fuerza socket_timeout=40 (> 30s del BRPOP), pero
# dejamos la version FIJADA para que la laptop y la PC usen
# exactamente lo mismo y no vuelva a romperse por una instalacion
# nueva de "redis" sin version.
#
# TODO: si actualizas alguna libreria, actualiza tambien esta
# linea y vuelve a probar el worker antes de moverlo de maquina.
# ============================================================
